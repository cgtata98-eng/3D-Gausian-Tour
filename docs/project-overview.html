3D_CG_GS — プロジェクト概要

3ds Max → Vantage で書き出したマンション CG を 3D Gaussian Splatting (3DGS) として軽量化し、 PlayCanvas Engine 上で回遊できるルームツアーとして配信するアプリケーション。 Project / Debug / Viewer の 3 画面構成で、開発者は編集 UI、閲覧者は URL 共有でアクセスする。

Vite 8 React 19 TypeScript 6 PlayCanvas 2.17 Zustand 5 three.js 0.183 IndexedDB

画面 / ルーティング

#/project プロジェクト選択画面（デフォルト着地）。ProjectScreen.tsx
#/scene/{id} デバッグモード — 編集 UI、視点・図面・コリジョン編集。DebugViewer.tsx
#/viewer/{id} 閲覧者モード — シンプル UI、URL 共有用。Viewer.tsx

ハッシュルーター実装は src/utils/url.ts（parseRoute()）。 ?mode=dev で開発者 UI を有効化（ui-store.isDeveloper）。

データモデル（2 階層分離）

SceneManifest(全体: 物件 ID / 名前 / 設定) × Plan[](間取りプラン: splat / 視点 / 図面 / コリジョン / info) の 2 階層に厳密に分離。 

SceneManifest {
  id, name                       // 物件アイデンティティ
  settings: SceneSettings        // カメラ高さ・速度・コリジョン径・FOV/Pitch 上限
  plans: Plan[]                  // プラン配列 (空でない保証あり)
}

Plan {
  id, label
  splat?                         // 3DGS ファイル (path / data: / blob: / idb:)
  panoramas?: Record<vpId, str>  // 360° モード用
  thumbnails?: Record<vpId, str> // 手動サムネ (auto はランタイムのみ)
  info?: SceneInfo               // type / roomType / area / floor / location / notes
  floorPlan?: FloorPlanConfig    // 図面画像 + worldToImage 変換
  collision?: CollisionConfig    // walkable / block GLB
  viewpoints: Viewpoint[]        // 視点配列 (空可)
  fixedPosition?: FixedPosition  // initialPositionMode='fixed' 時の初期姿勢
}

Viewpoint {
  id, label, position, target, fov
  mapPosition?  // 図面ドット位置 (camera と分離 — 撮影位置を維持)
  mapYaw?       // 図面コーン向き (camera と分離 — 手動調整を維持)
}

旧トップレベル (splat/info/collision/floorPlan/viewpoints) を持つ scene.json は、 ストア読込時に synthesizeDefaultPlan() → stripLegacyTopLevelFields() で plans[0] に自動マイグレーションされる。

プロジェクト一覧 (Project[])

  • 永続化: localStorage / 3droomtour:projects:v1

  • エンジン側 camera-controller と双方向同期
