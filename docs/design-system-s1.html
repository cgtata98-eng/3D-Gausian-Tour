3DRoomTour デザインシステム — S1 透過シェル

エッジは S1（上辺＝影 / 左右＝素材色 / 下辺＝白）。 文字はバリアントと同系色で、掘り込み（レタープレス）にしています。 掘った溝を上から照らすと上壁が影・下壁が受光になるので、文字の陰影も「上が影・下が白」。 S1 の縁とまったく同じ光源モデルなので、縁と文字で矛盾が起きません。 面のグラデーションと外側ドロップシャドウは design-tokens.ts の実値そのままです。 ボタンやカードにマウスを乗せると縁を光が一周します。
