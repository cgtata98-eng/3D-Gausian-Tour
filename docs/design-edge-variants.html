透過シェルのエッジ

ご指摘のとおりでした。参照スクショを拡大して実測した結果、縁の構造は 上＝影 / 左右＝色 / 下＝白で、暖色はどこにも入っていません。 前回のオレンジは私の捏造でした。撤去しています。縁の幅も 1.2px 前後まで絞り、広いブルームは廃止しました。

この構造には物理的な理由があります。「上から光を受けた薄い透明シェル」の見え方です。

  • 上 — 見込み角が浅く、シェルの厚みを edge-on で見ることになるので暗くなる（シャボン玉の上縁と同じ）
  • 左右 — 視線が素材を最も長く通過するので、その素材の色が最も溜まる。反射ではなく透過の色です
  • 下 — 上から入った光が屈折して下縁から出る。コースティクス。だから白く抜ける

そして現行が glass に見えない決定的な理由も、これで判明しました。 現行の内側の影は inset 0 2px 2px rgba(255,255,255,.85)（上が白）と inset 0 -1px .5px rgba(40,48,80,.07)（下が暗い）で、参照と上下が完全に逆です。 現行は「上から光を受けた不透明な物体」のモデル、参照は「透明なシェル」のモデル。 ここを反転させない限り、縁に何層足してもガラスにはなりません。以下 4 案はすべて反転させています。
